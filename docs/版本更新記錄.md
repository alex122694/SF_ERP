# SF ERP 版本更新記錄

> 輕量版（Lite）的功能變更彙整，依日期由新到舊。資料檔升級由系統開啟時自動完成（schema 版本見下方「資料檔」欄），升級前請先備份 `data\`。
> 詳細規則請見 `docs/規格.md`。

## 2026-10-22（最新）

**資料檔：schema 第 8 版**

### 薪資與時數規則
- **全日請假算 8 小時**：請整天（涵蓋整個工作時段）直接算 1 天 8h，不是 7.5h；上午 2.5h、下午 5h，自選時段照實際重疊時數計算
- **遲到上限 12:00**：遲到從 09:30 算到實際到班時間（09:31～12:00），12:00 以後請登記上午請假；分鐘數扣除午休
- **整天扣款直接用日薪**：整天（8h）的扣款 = 日薪（月薪 ÷ 30）× (1 − 給薪比例)，不經時薪；不足一天才用 時數 × 時薪（金額結果與以往相同，只是計算路徑改變）
- **同人同天同假別只能一筆**；不同假別可以並存
- **扣款先依假別加總取整，再相加成總額**：每筆紀錄存不取整的金額；統計與匯出把同一員工、同一假別的各筆加總後四捨五入，再把取整完的各假別金額相加；單筆畫面顯示四捨五入後的整數，所以同假別的各筆相加可能與該假別金額差 1 元（升級時既有紀錄依已存時數與薪資重算）
- 特休一律以天顯示，不再提供小時切換

### 首頁
- **「現在不在座位」依目前時間顯示**：只列出此刻落在請假時段內的人（上午假只在上午、下午假只在下午顯示），遲到不算不在座位；標題旁顯示即時時間並每秒刷新

### 請假總覽與匯出
- **月結區間**：結算日每月 22 日，「N 月」= 上月 23 日 ～ N 月 22 日（1 月跨前一年 12/23；「全年」= 前一年 12/23 ～ 當年 12/22），預設為今天所屬的月結月份
- **指定區間**：自選起日、迄日
- **匯出選項視窗**：
  - 金額試算總覽（每位員工一列：假別、時數、扣款金額、總扣款金額）
  - 請假明細總覽（一筆紀錄一列：姓名、部門、日期、假別、時間、時數）
  - 匯出對象：全部員工、勾選部門、勾選人員
- 匯出檔名為 `請假總覽_起日~迄日.xlsx`、`請假明細總覽_起日~迄日.xlsx`
- 首頁「本月」數字、出缺勤月曆、員工個人頁仍以曆月計算

### 登記請假
- **選起始日與結束日一次登記多天**：每個上班日各存一筆，放假日自動略過；第一天與最後一天可各自設定時段，中間一律全天；逐日檢查（特休額度、時段重疊會累計），任何一天不行就整批不登記並指出是哪一天；一次最多 92 天（遲到與月曆編輯既有紀錄仍是單日）

### 假別
- **新增「曠職」假別**：不給薪、最小單位 30 分鐘、送出前雙重確認、簡字「曠」；出缺勤月曆上方新增「曠職快速導覽列」，點一筆即開啟編輯，方便補請假時改成正確假別（舊資料檔升級時自動補上）

### 員工與其他
- **員工部門**（可為空）：在「制度與設定」維護部門清單（新增、改名、刪除；有員工的部門不能刪除）；員工主檔可選部門、列表可依部門篩選與搜尋、CSV 匯出含部門
- **備忘錄**：側邊選單新增，自由文字記事本，自動儲存於資料檔（隨備份保存，上限 20000 字）
- **從備份還原**：「制度與設定 → 資料檔與備份」新增「從備份還原」，選 `sf_erp-YYYYMMDD.sqlite` 備份檔，確認內容摘要後整份取代目前資料；取代前目前的資料自動另存為 `backup\sf_erp-before-restore-…sqlite`
- **更新工具**：新增 `update-lite.bat`，從 GitHub 抓最新 `release/SF ERP-lite.zip` 並解壓縮到指定資料夾（有 git 用 git，沒有則用唯讀 token 經 API 下載），不動 `data\`

## 2026-10-21

**資料檔：schema 第 5 版**

- **員工改以離職日處理**：有出缺勤或特休處理紀錄的員工不能刪除，改填離職日；只有完全沒有紀錄的員工（例如建錯的資料）可以刪除
- **扣款依登記當時薪資**：`leave_record` 新增 `salary`，編輯舊紀錄時以該筆登記當時的月本薪重算，不回溯調薪；既有紀錄以升級時的薪資補上
- 規格依實作更新（特休半天單位、手動改日原因、追蹤起算日、請假總覽匯出 Excel、資料表欄位）
- 新增 `docs/系統分析報告.html`、`docs/Lite-README.html`、Lite 使用說明

## 2026-10-20

**資料檔：schema 第 4 版以前**

- **特休改以半天為單位**（上午／下午 4h、全天 8h），資料庫升級時換算舊紀錄
- **手動改放假日／上班日必須填原因**，可由快選清單選取，可在制度與設定修改
- **請假總覽**：姓名／本薪／總扣款跨列合併、性別淡色底；匯出改為置中對齊的 Excel
- **快速登記**：出缺勤月曆按鈕、送出鈕置中、送出後跳轉開關
- **四語言介面**（中文、English、日本語、한국어），主題與語言記在瀏覽器
- 掃描問題修復；加入輕量版發佈檔 `release/SF ERP-lite.zip`

## 2026-10-19

- **SF ERP v2.0**：輕量版（單一檔案 HTML + SQLite，Chrome／Edge 直接開啟）與 v1.2 修正；功能含首頁與提醒、快速登記、出缺勤月曆、員工主檔、員工個人頁、請假總覽、制度與設定、特休到期處理

## 升級注意事項
- 解壓縮新版 zip 到原路徑時，`data\`（`sf_erp.sqlite` 與 `backup\`）不在 zip 內，不會被覆蓋；請勿先刪除舊資料夾再解壓縮
- 同一份資料同一時間只讓一台電腦開啟
- 標準版（Java）的規則需與輕量版同步：全日 8h、遲到上限、同日同假別一筆、扣款逐筆加總後取整，並以 `shared/rules-cases.json` 驗證
